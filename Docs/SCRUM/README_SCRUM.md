# SCRUM - Ecos del Aula

## Objetivo del producto
Ecos del Aula es un videojuego educativo sobre convivencia digital, bullying y ciberacoso en contextos academicos. El producto busca que el jugador aprenda a identificar conductas daninas, revisar contexto, tomar decisiones y recibir retroalimentacion clara.

## Roles aproximados
- Product Owner: responsable de priorizar las necesidades educativas y de jugabilidad.
- Scrum Master: responsable de cuidar el proceso, remover bloqueos y mantener reuniones breves.
- Development Team: responsable de implementar gameplay, UI, arte, audio, QA y documentacion.

## Forma de trabajo
El trabajo se organiza por historias de usuario en el Product Backlog. En cada sprint se seleccionan tareas concretas, se implementan, se prueban en Unity y se revisan antes de hacer commit o push.

## Reglas de revision
- No se integra trabajo sin compilar.
- No se aceptan errores rojos en consola.
- No se aceptan UI duplicadas o paneles invisibles bloqueando input.
- No se hacen commits sin revision manual del estado de Git.
