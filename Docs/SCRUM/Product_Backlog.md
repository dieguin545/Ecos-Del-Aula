# Product Backlog

## Historias de usuario
- Como estudiante, quiero identificar mensajes de ciberacoso para aprender a responder correctamente.
- Como jugador, quiero navegar por la PC virtual para revisar correos, casos, tienda y ayuda.
- Como jugador, quiero recibir feedback visual y sonoro para entender mis decisiones.
- Como usuario con control, quiero que los prompts cambien automaticamente entre teclado y Xbox.
- Como jugador, quiero que Vida Escolar muestre mis tareas y evidencias claramente.
- Como jugador, quiero que Firewall del Aula represente mensajes daninos, no violencia contra personas.
- Como jugador, quiero que los menus funcionen con teclado, mouse y control.
- Como docente/evaluador, quiero que el proyecto sea estable y defendible academicamente.

## Prioridad actual
1. Estabilidad de escenas y pausa.
2. UI legible y no duplicada.
3. Control Xbox/teclado persistente.
4. Feedback claro en Juego2 y Firewall del Aula.
5. Limpieza de assets sin romper referencias.
