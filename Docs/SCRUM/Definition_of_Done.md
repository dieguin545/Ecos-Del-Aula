# Definition of Done

Una tarea se considera terminada cuando:

- Unity compila sin errores.
- No hay errores rojos en consola.
- No hay NullReferenceException ni MissingReferenceException nuevos.
- La UI no queda duplicada.
- No hay paneles invisibles bloqueando clicks.
- Se prueba teclado y mouse.
- Se prueba o prepara validacion con control Xbox.
- Se valida PC virtual cuando el cambio toca input o camara.
- Se valida Juego2 cuando el cambio toca HUD, pausa, evidencias o ansiedad.
- Se valida Firewall del Aula cuando el cambio toca SpaceShooter.
- No se hacen commits, merges, pulls ni pushes sin revision manual.
